# #6 实验报告：长序列 state MSE

## 概述

测试量化误差是否在长序列中累积导致状态发散。RWKV 的 state 更新包含衰减+擦除+注入，理论上小误差可能复合放大。

## 实验方法

1. 用原始模型贪心生成了 8192 tokens（从 test_2100 前 100 tokens 起步）
2. 在 8192 tokens 上运行原始模型和量化模型
3. 按位置窗口计算 Top-1 和 PPL delta

## 实验结果

| 窗口 | 6a NVFP4 Top1 | 6a PPL_d | 6b FP8 Top1 | 6b PPL_d |
|------|---------------|----------|--------------|----------|
| 0-512 | 97.66% | +0.0147 | 99.22% | +0.0013 |
| 512-1024 | 100.00% | +0.0004 | 100.00% | 0.0000 |
| 1024-2048 | 100.00% | +0.0002 | 100.00% | 0.0000 |
| 2048-4096 | 100.00% | +0.0002 | 100.00% | 0.0000 |
| 4096-8192 | 100.00% | +0.0002 | 100.00% | 0.0000 |

## 关键发现

### 量化误差不累积
- Top-1 在后续窗口达到 100%，无下降趋势
- PPL delta 稳定在 ~0.0002（NVFP4）和 0.0000（FP8）
- **结论：state 不会因量化误差发散**

### 0-512 窗口退化较多
- 包含原始 prompt（前 100 tokens），预测难度更高
- 量化模型在"困难"位置表现略差，但在"简单"位置（模型自生成文本）完美

### RWKV state 衰减机制天然抑制误差累积
- 全局衰减 `S = diag(w_delta) · S` 每步缩小 state
- 旧误差被衰减，新信息持续注入
- 与 RNN 不同，RWKV 的 state 有自修复特性

## 结论

- 量化在 8192 tokens 长序列上无累积误差
- 无需为长序列场景做特殊量化处理
- state 衰减机制天然抑制误差传播
